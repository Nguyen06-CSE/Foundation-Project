🧭 1. Lộ Trình Đọc Tài Liệu Theo Vai Trò (Persona Roadmap)​

Để giúp các bên liên quan tiếp cận tài liệu nhanh chóng và đúng trọng tâm, hãy chọn vai trò của bạn dưới đây để nhận lộ trình 4 bước tối ưu nhất:

🎯

Dành cho Frontend / Backend Engineers cần cài đặt môi trường, hiểu API contract và nắm quy trình commit/test.

Trọng tâm: Chạy Localhost 100% offline, cấu hình biến môi trường và tra cứu 128 REST endpoints.

BƯỚC 01
Khởi Chạy Localhost 5 Phút
Cài đặt và khởi chạy toàn bộ Backend FastAPI + Frontend React mà không cần Internet.
BƯỚC 02
Ngăn Xếp Công Nghệ
FastAPI, Async SQLAlchemy 2.0, React 19, TailwindCSS và PostgreSQL GIN Index.
BƯỚC 03
Tra Cứu 128 API Endpoints
Danh mục API đầy đủ, quy ước RESTful, chuẩn lỗi và cơ chế xác thực JWT Bearer.
BƯỚC 04
Quy Trình Phát Triển
Quy chuẩn đặt tên nhánh, linting oxlint, kiểm thử pytest và Alembic migrations.

🏛️ 2. Sơ Đồ Kiến Trúc Hệ Thống & Luồng Dữ Liệu Tương Tác​

Bản vẽ kiến trúc toàn diện mô phỏng mô hình Client - Server, ranh giới tin cậy, quy trình băm SHA-256 Deduplication, cơ chế lưu trữ Hybrid Cloudflare R2 / Local Storage và bộ xử lý nền BackgroundTasks.

Sơ Đồ Kiến Trúc Hệ Thống (System Architecture)
Mở Tab Mới
Khởi Chạy Local Nhanh 100% Không Cần Internet

Toàn bộ mã nguồn Backend FastAPI, CSDL PostgreSQL và Frontend React được thiết kế theo chuẩn Offline-First. Bạn có thể thiết lập và khởi chạy toàn bộ hệ thống trên máy cá nhân trong vòng 5 phút bằng cách làm theo hướng dẫn tại Khởi Chạy Localhost.

Khám phá 3 trụ cột kỹ thuật nền tảng tạo nên sức mạnh và độ tin cậy của nền tảng Thư viện số:

📋
RBAC 5 Roles

Khảo sát mục tiêu kinh doanh (BRD), yêu cầu chức năng (FRD), phi chức năng (NFR), ma trận phân quyền 5 cấp và 6 luồng Use Cases cốt lõi.

🏛️
Hybrid R2 & C4
Kiến Trúc Hệ Thống & 5 ADRs
Mô hình kiến trúc C4, cơ chế lưu trữ Hybrid Cloudflare R2 kết hợp Localhost, thuật toán chống trùng lặp SHA-256 và 5 quyết định kiến trúc then chốt.

✨ 4. Bản Đồ 10 Phân Hệ Tính Năng Nghiệp Vụ (feat/)​

Toàn bộ nghiệp vụ của nền tảng được module hóa thành 10 phân hệ độc lập, có đầy đủ đặc tả API, Schema CSDL, Quy tắc nghiệp vụ và Minh họa giao diện:

📂
Core Storage
1. Personal Dashboard & Kho Cá Nhân
Quản lý tài liệu cá nhân, cây thư mục đa cấp (Folder = Kệ sách Tag), gắn nhãn màu sắc và thùng rác lưu trữ 30 ngày có cơ chế khôi phục an toàn.
Xem chi tiết phân hệ
🏫
Open Education
2. Community Library & Môn Học
Thư viện học liệu mở phân tầng theo Khoa, Ngành và Học phần. Cơ chế Fork / Copy-on-Share tài liệu về kho cá nhân hoàn toàn độc lập.
Xem chi tiết phân hệ
🔗
Security Sharing
3. Document Sharing & Phân Quyền Link
Chia sẻ tài liệu qua liên kết bảo mật có mật khẩu bảo vệ, giới hạn thời gian hết hạn và cấu hình quyền xem / tải xuống linh hoạt.
Xem chi tiết phân hệ
🔍
PostgreSQL GIN
4. Document Query & Full-Text Search
Tìm kiếm toàn văn tiếng Việt không dấu (unaccent), tìm kiếm mờ Trigram (pg_trgm) trên cột tsvector tự động cập nhật qua PostgreSQL Trigger.
Xem chi tiết phân hệ
🖥️
UI Experience
5. Document View Modes (Grid / List / Detail)
Chuyển đổi 3 chế độ xem: Lưới thẻ (Grid), Danh sách thu gọn (List) và Khung chi tiết (Detail) có hộp xem trước văn bản và trích xuất OCR.
Xem chi tiết phân hệ
📝
Web Native
6. Markdown Viewer & Publisher
Trình đọc văn bản Markdown phong phú với công thức toán học KaTeX, Highlight code cú pháp, sanitize DOM chống XSS và tính năng export HTML.
Xem chi tiết phân hệ
📦
Batch Pack
7. Document Bundle & Trọn Bộ Học Liệu
Đóng gói trọn bộ giáo trình, slide bài giảng và đề thi thành một Bundle duy nhất. Cho phép người học tải về toàn bộ dưới dạng file nén ZIP một chạm.
Xem chi tiết phân hệ
🖼️
Multi-format OCR
8. Preview & Quản Lý Cover/Thumbnails
Xem trước trực quan PDF, DOCX, Code; tự động gộp nhiều ảnh chụp slide thành file PDF qua jsPDF và chạy OCR Tesseract bóc tách chữ.
Xem chi tiết phân hệ
📊
Trending Score
9. Activity Tracking & Điểm Xu Hướng
Hệ thống telemetry ghi nhận lượt xem, tải xuống, đánh giá sao. Thuật toán suy giảm thời gian (Exponential Decay) tính điểm Trending tài liệu hot.
Xem chi tiết phân hệ
🚀
Productivity
10. System Enhancements 2026
Thanh tác vụ nổi hàng loạt (Bulk Action Bar), nhãn gắn linh hoạt cấp Workspace, trung tâm thông báo thời gian thực và quản lý tài khoản người dùng.
Xem chi tiết phân hệ
