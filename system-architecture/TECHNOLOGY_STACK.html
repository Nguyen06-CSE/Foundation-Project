🛠️ Ngăn Xếp Công Nghệ Chuẩn Hóa (Technology Stack)

Tài liệu này tổng hợp toàn bộ các công nghệ, framework, thư viện và công cụ được sử dụng trong dự án Digital Library, đối chiếu trực tiếp từ các tệp cấu hình thực tế (backend/requirements.txt và frontend/digital-library/package.json), kèm theo cơ sở lý luận lựa chọn và đánh đổi kỹ thuật.

1. Ngăn Xếp Tầng Máy Chủ (Backend Stack)​

Thành phầnCông nghệ / Thư việnPhiên bảnLý do lựa chọn & Lợi ích kỹ thuậtĐánh đổi kỹ thuật (Trade-offs)
Ngôn ngữPython3.11+Hiệu năng xử lý nhanh hơn 25-60% so với 3.10; hệ sinh thái thư viện xử lý tài liệu (PDF, Word, OCR) phong phú nhất thế giới.Tốc độ xử lý thô CPU-bound chậm hơn Go/Rust.
FrameworkFastAPI0.111.0Hỗ trợ Asynchronous tự nhiên (async/await), tự động sinh tài liệu Swagger UI, hiệu năng tiệm cận NodeJS và Go.Đòi hỏi lập trình viên phải nắm vững lập trình bất đồng bộ.
ASGI ServerUvicorn + uvloop0.30.1Event loop viết bằng C (uvloop), cung cấp thông lượng I/O cực cao cho các tác vụ truyền file.Yêu cầu môi trường tương thích POSIX/Linux.
ORM & DatabaseSQLAlchemy2.0.31Chuẩn ORM số 1 của Python; hỗ trợ AsyncSession bất đồng bộ hoàn toàn với driver asyncpg.Cú pháp phiên bản 2.0 chặt chẽ, đường cong học tập cao hơn 1.4.
Database Driverasyncpg0.29.0Driver kết nối PostgreSQL nhanh nhất trong hệ sinh thái Python, tối ưu hóa giao tiếp TCP nhị phân.Không tương thích trực tiếp với các câu lệnh đồng bộ (sync).
Data ValidationPydantic V22.7.4Phần core viết bằng Rust giúp serialize/deserialize dữ liệu nhanh gấp 5-10 lần Pydantic v1.Một số thay đổi cú pháp đột phá so với phiên bản V1.
Database MigrationAlembic1.16.5Quản lý lịch sử thay đổi cấu trúc bảng cơ sở dữ liệu có phiên bản, hỗ trợ rollback an toàn.Cần cấu hình bổ sung khi chạy ở chế độ Async Engine.
Cloud Storageboto31.43.112SDK S3 tiêu chuẩn công nghiệp của AWS, tương thích 100% với giao thức Object Storage của Cloudflare R2.Kích thước gói thư viện tương đối nặng.
Job SchedulingAPScheduler3.11.3Lập lịch tác vụ định kỳ trong tiến trình (In-process cron jobs) cho dọn rác 30 ngày và suy hao điểm trending.Chạy đơn tiến trình; khi mở rộng multi-instance cần chuyển Redis.
Trích xuất Text & OCRpytesseract & pdfplumber0.3.13Trích xuất văn bản từ tệp PDF và nhận diện chữ tiếng Việt từ ảnh scan phục vụ tìm kiếm toàn văn FTS.Tiêu tốn tài nguyên CPU khi xử lý tệp scan có độ phân giải cao.

2. Ngăn Xếp Tầng Khách Hàng (Frontend Stack)​

Thành phầnThư việnPhiên bảnLý do lựa chọn & Lợi ích kỹ thuậtĐánh đổi kỹ thuật (Trade-offs)
Thư viện UI LõiReact19.2.8Hỗ trợ các tính năng đồng thời (Concurrent Features), Server Actions và tối ưu hóa chu kỳ render.Phiên bản mới cần kiểm tra tương thích với một số thư viện cũ.
Build ToolVite8.2.2Tốc độ biên dịch Hot Module Replacement (HMR) tức thì dưới 50ms nhờ kiến trúc Native ESM và Esbuild.Cấu hình plugin SSR phức tạp hơn Next.js.
Ngôn ngữTypeScript~6.0.2Kiểm soát chặt chẽ kiểu dữ liệu từ API (types/), giảm thiểu 95% lỗi runtime undefined.Tăng thời gian viết code ban đầu để định nghĩa interface.
Styling FrameworkTailwind CSS v44.3.3Động cơ Oxide viết bằng Rust, cấu hình trực tiếp qua CSS không cần file tailwind.config.js.Lớp giao diện mới cần thời gian làm quen với Tailwind 4 engine.
Server State CacheTanStack React Query5.102.8Quản lý bộ nhớ đệm dữ liệu từ máy chủ (caching, invalidation, optimistic updates, background refetch).Cần phân biệt rõ Server State (Query) và Client State (Zustand).
Client State StoreZustand5.0.15Quản trị trạng thái cục bộ cực nhẹ (< 1KB), cú pháp đơn giản, không cần bọc Provider rườm rà như Redux.Ít middleware phức tạp dựng sẵn so với Redux Toolkit.
RoutingReact Router7.18.3Chuẩn điều hướng trang đơn (SPA) số 1 của hệ sinh thái React.Phiên bản v7 gộp nhiều khái niệm từ Remix.
DOCX Viewerdocx-preview0.4.1Dựng trực tiếp file Word sang thẻ HTML tại trình duyệt, không cần máy chủ chuyển đổi file.Khả năng dựng hình một số bảng biểu phức tạp có thể lệch nhẹ.
Code Syntax HighlightingShiki4.5.0Bộ tô màu cú pháp dùng TextMate Grammars chuẩn VS Code, hiển thị màu sắc code cực kỳ chuẩn xác.Kích thước bundle ngôn ngữ khá lớn nếu không nạp lười (lazy load).
Linter Siêu TốcOxlint1.79.0Bộ kiểm tra lỗi viết bằng Rust, chạy nhanh hơn ESLint từ 50 đến 100 lần trong quá trình phát triển.Hệ sinh thái plugin chưa phong phú bằng ESLint truyền thống.

3. Hạ Tầng Dữ Liệu & Lưu Trữ (Data & Storage Stack)​

  • Hệ Quản Trị Cơ Sở Dữ Liệu: PostgreSQL 14 / 15 / 16
    • Lý do: Khả năng mở rộng mạnh mẽ, hỗ trợ kiểu dữ liệu nhị phân JSONB, bộ lập chỉ mục chuyên dụng cho tìm kiếm toàn văn (tsvector, tsquery), và phần mở rộng tính độ tương đồng xâu ký tự pg_trgm.
  • Hạ Tầng Lưu Trữ Đối Tượng Đám Mây: Cloudflare R2 Object Storage
    • Lý do: Tương thích hoàn toàn chuẩn giao thức Amazon S3 API; đặc biệt có chính sách 0đ phí truyền dữ liệu ra ngoài (Zero Egress Fees), giúp nhà trường loại bỏ hoàn toàn chi phí phát sinh khi hàng ngàn sinh viên tải tài liệu ôn tập.
  • Hạ Tầng Lưu Trữ Cục Bộ (Fallback): Local Filesystem Buffer (backend/storage/)
    • Lý do: Cho phép hệ thống tự động rơi về chế độ lưu trữ cục bộ khi mất mạng hoặc khi developer chạy đồ án ở chế độ Offline 100%.

4. Công Cụ Tài Liệu & Tự Động Hóa (DevOps & Documentation)​

  • Documentation Platform: Docusaurus 3.10.2 (React 19, @docusaurus/preset-classic, @docusaurus/theme-mermaid).
  • Hosting & CDN Tài Liệu: GitHub Pages (triển khai tự động từ nhánh gh-pages).
  • CI/CD Pipeline: GitHub Actions (Workflow .github/workflows/deploy-docs.yml tự động build và deploy khi có commit mới vào nhánh main).
  • Phân Tích Đồ Thị Tri Thức: Graphify Engine (Theo dõi cây phụ thuộc mã nguồn AST-only với 3.397 nodes và 8.765 edges).
