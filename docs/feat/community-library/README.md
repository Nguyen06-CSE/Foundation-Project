# 🏫 Phân Hệ 2: Community Library & Kho Học Liệu Mở

Chào mừng bạn đến với tài liệu phân hệ **Community Library** (Thư viện cộng đồng học thuật) của hệ thống Thư viện số. Phân hệ cung cấp không gian chia sẻ tài liệu học tập mở phân tầng theo Khoa, Ngành và Học phần, giúp sinh viên và giảng viên dễ dàng tiếp cận nguồn tri thức phong phú.

---

## 📑 Danh Mục Tài Liệu Phân Hệ

1. 📋 **[Đặc Tả Kỹ Thuật Nghiệp Vụ (Spec)](./spec.md)**:
   - Mô hình phân cấp Khoa $\rightarrow$ Ngành $\rightarrow$ Học phần $\rightarrow$ Học liệu.
   - Cơ chế đóng góp tài liệu từ kho cá nhân lên thư viện mở.
   - Nguyên tắc sao chép độc lập (Copy-on-Share / Fork).
2. 🛠️ **[Triển Khai Kỹ Thuật (Implementation)](./implementation.md)**:
   - Kiến trúc tích hợp Frontend React và Backend FastAPI.
   - Chi tiết danh sách API endpoints tra cứu và lọc theo cây học thuật.
3. ⚙️ **[Mở Rộng Quản Lý & Phê Duyệt (Management Extension)](./management-extension.md)**:
   - Quy trình kiểm duyệt tài liệu dành cho Giảng viên và Ban cán sự học tập.
   - Phê duyệt, từ chối và phản hồi lý do kiểm duyệt.
4. 🐛 **[Báo Cáo Sửa Lỗi Đếm Số Lượng Tài Liệu (Bug Fix Report)](./bug-fix-document-counting.md)**:
   - Phân tích nguyên nhân và giải pháp sửa lỗi đếm sai số lượng tài liệu trong các danh mục học phần.
